# Apki Manzil 🏠

A modern, responsive real estate website built with **Next.js, TypeScript, and Tailwind CSS**, focused on property discovery and real estate services in **Lahore, Pakistan**.

## 🚀 Overview

**Apki Manzil** provides a clean and user-friendly platform for browsing residential and commercial properties in Lahore.

The website is designed with a modern real estate experience, responsive layouts, intuitive property browsing, and clear contact functionality.

## ✨ Features

* 🏠 Property listings and property details
* 🔎 Property search and filtering
* 📍 Lahore-focused property information
* 🏡 Residential and commercial property categories
* 📱 Fully responsive design for mobile, tablet, and desktop
* 🎨 Modern and clean user interface
* ⚡ Fast navigation with Next.js
* 📄 Dedicated property detail pages
* 📞 Contact/inquiry form
* 🗂️ Structured local property data
* 🔗 SEO-friendly page structure
* 🌙 Modern UI with responsive design

## 🛠️ Tech Stack

* **Next.js**
* **React**
* **TypeScript**
* **Tailwind CSS**
* **Lucide React**
* **Next.js App Router**
